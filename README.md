AstloHorizon
____________


a plugin for astlo that utilizes open source ephemeris files from NASA-JPL. it acts as a purifier for Luna states since astlo only shows tge mean states for luna.

if you check astlo Heliocentric and Barycentric states against astlohorizons states, you will realise a diffrence of about 200000km for the planets/dwarfs/asteroids.

astlo is the main core engine that handles the vector math and other numeric arithmetics.

The CLI part is self explanatory.


The SDK part of astlohorizon as of v0.1.1:
    class Asho
        _init_
        method skysolsys
        method luna
        method lunaface
        method osci
